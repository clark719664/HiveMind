The toy's defaults were chosen to make the effect visible, so its numbers must never be quoted as results about real LLM training. The real measurements (section "What the real experiments measured") are small, single-machine runs on one time-shared GPU; the core E13 and E14 experiments were registered in the repository before they were run, the rotating-straggler and M=2 runs are labelled diagnostics, and everything is assessed by the project itself. No peer review of record exists for the project. Nothing on this page needs a network, an account or a GPU.

HiveMind: training together on ordinary GPUs

HiveMind is an open-source research project on training and serving mixture-of-experts language models across many consumer GPUs, using DiLoCo-style training in which each worker takes many local steps and only occasionally sends the change it made (its delta) to a coordinator.

A coordinator has to decide whom to wait for: waiting for every worker is slow, but merging only the first few can starve the data domain of a slow worker, and the project measures when that happens and which admission rules help.

This page lets you play with a tiny, deterministic toy of that one question, shows the numbers from the real experiments next to it with their sources, and invites you to extend the toy or the experiments.

Swarm Lab

Each of M workers owns one data domain (a quadratic loss with its own optimum). Every round they take noisy local steps, report a delta, and the coordinator waits for the K-th arrival plus a grace window, then merges what it has. Retention is the share of the synchronous improvement that the swarm keeps: 1 means as good as waiting for everyone, 0 means nothing learned. Toy model, 16 parameters, deterministic (the same JavaScript engine matches the Python simulator to 1e-9).

What the real experiments measured

    
These panels are generated from the experiment reports in artifacts/experiments/ (see scripts/build_site_data.py). Every block carries the file it came from and the first 12 characters of that file's receipt hash. Status words (supported, refuted, inconclusive, descriptive, invalid) are copied from the registered analysis files; where a wording comes from the campaign report instead, or was derived from a report field by a registered rule, the block says so. The toy above is an analogy of these results, not a model fitted to them.

Run the Python simulator (standard library only, no GPU):

    
python3 scripts/swarm_lab.py simulate --preset persistent-straggler
python3 scripts/swarm_lab.py compare --preset persistent-straggler
python3 scripts/swarm_lab.py play --auto

    
Check that your change keeps the JavaScript and Python engines identical: python3 -m pytest tests/test_swarm_lab.py tests/test_swarm_lab_js_parity.py.
