## 2. Multi-Vendor GPU Backend Support & Opt-In Community GPU Benchmark

Configured via [`src/hivemind/config.py`](https://github.com/xaviercallens/HiveMind/blob/main/src/hivemind/config.py), [`PinnedRAMExpertDMAStreamer`](https://github.com/xaviercallens/HiveMind/blob/main/src/hivemind/swarm/swarm_fabric.py), and [`src/hivemind/cli/community_gpu_benchmark.py`](https://github.com/xaviercallens/HiveMind/blob/main/src/hivemind/cli/community_gpu_benchmark.py):
- **NVIDIA CUDA (`cuda_stream`):** Dedicated secondary `torch.cuda.Stream` + `pin_memory()` double-buffered slots (`slot_A` / `slot_B`).
- **AMD ROCm (`hip_stream`):** Native HIP stream dispatch on RDNA3 (`gfx1100` native `bf16`) and RDNA2 (`gfx1030` `fp16` fallback).
- **Apple Silicon (`mps_unified`):** Unified memory zero-copy tensor staging on M1/M2/M3/M4 GPUs.
- **CPU Fallback (`cpu_copy`):** Deterministic execution for headless CI and verifier nodes.
